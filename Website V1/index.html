Why Multi LLM.Warum Multi LLM.

01

One endpoint for everythingEin Endpoint für alles

92 cloud and local providers behind a single local /v1 API. Switch models, compare outputs, or migrate providers – without rewiring a single tool.92 Cloud- und lokale Provider hinter einer einzigen lokalen /v1-API. Modelle wechseln, Ausgaben vergleichen oder Provider migrieren – ohne ein einziges Tool neu zu verkabeln.

02

Private by designPrivat per Design

Provider keys stay on your machine in a restricted local store and are compared as hashes. No account, no cloud, no telemetry – the website itself sets no tracking cookies either.Provider-Schlüssel bleiben auf deinem Rechner in einem geschützten lokalen Speicher und werden als Hashes verglichen. Kein Konto, keine Cloud, keine Telemetrie – und diese Website setzt ebenfalls keine Tracking-Cookies.

03

Built-in resilienceEingebaute Ausfallsicherheit

Automatic failover to the next model, health-based routing across 6 strategies, and a circuit breaker that parks failing providers. Your 3 a.m. deploy survives an outage.Automatisches Failover zum nächsten Modell, zustandsbasiertes Routing über 6 Strategien und ein Circuit Breaker, der fehlerhafte Provider parkt. Dein 3-Uhr-nachts-Deploy überlebt einen Ausfall.

04

Transparent costsTransparente Kosten

Per-model token ranking, request counts, JSON export for billing, and prompt compression (1–10) that shrinks traffic before it costs you money.Token-Ranking pro Modell, Request-Zähler, JSON-Export für die Abrechnung und Prompt-Kompression (1–10), die Traffic schrumpft, bevor er Geld kostet.

05

Your tools, unchangedDeine Tools, unverändert

Cursor, VS Code, IntelliJ, OpenCode and more connect with three values – URL, key, model. No plugins, no lock-in, no retraining muscle memory.Cursor, VS Code, IntelliJ, OpenCode und mehr verbinden sich mit drei Werten – URL, Key, Modell. Keine Plugins, kein Lock-in, kein Umlernen.

06

Team-readyTeamfähig

One Docker container on one port serves the whole team with isolated profiles, per-user keys, and an admin – while solo users get the same power as a desktop app.Ein Docker-Container auf einem Port versorgt das ganze Team mit isolierten Profilen, Schlüsseln pro Nutzer und Admin – während Solo-Nutzer dieselbe Power als Desktop-App bekommen.

Ready to put every model behind one API?Bereit, alle Modelle hinter eine API zu packen?
