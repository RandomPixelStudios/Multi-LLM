Questions

FAQ

Short answers to what people ask most often, grouped by what they were trying to do.

General

What does Multi LLM actually do?

It puts every LLM provider you have keys for behind one local OpenAI-compatible endpoint, so one URL and one key work in every tool. It also routes between models, fails over when a provider breaks, and keeps your keys on your machine.

Do I need an account?

Only for the app itself, and it stays on your machine. There is no sign-up, no e-mail address and no external login. Passwords are stored as argon2id hashes.

Does it send my data anywhere?

Only to the provider you selected, because that is what a model request is. There is no telemetry, no analytics and no account. The one optional outbound request is the update check, which you can switch off.

Is it free?

The software is free to install. Your providers bill you directly, and the usage panel estimates what that costs. Local models cost no tokens but use your own electricity and hardware.

Is it stable enough for daily work?

It is beta. The API shape may change between versions. Export your configuration before updating, and expect to read release notes.

Connecting a tool

The tool still talks to api.openai.com

The base URL field name does not match what the tool expects, so it ignored your value and used its own default. The field name table lists the name per tool family. This is by far the most common problem.

Do I need the /v1 at the end?

Almost always yes. Claude Code is the exception: it wants the bare address, because it appends the Anthropic path itself.

Why does the model list in my tool stay empty?

Most tools do not call GET /v1/models. They use whatever you type. Enter multillm or a real model id by hand.

The tool cannot find localhost

The tool runs somewhere else than the proxy. In a container, localhost is that container — use host.docker.internal. In a browser-based tool on another device, use your LAN address and switch on Expose to LAN.

Streaming stops mid-sentence

Compare with streaming off. If it works, the tool does not handle the provider's keep-alive chunks. The workaround is to disable streaming for that tool.

My tool asks for an API key but I do not have one

Any string works as a local key, but generate the real one in API › API Keys. A key with model and rate limits is better than one shared by every tool.

Providers and models

A provider shows no models

The key is wrong, the base URL does not match, or the provider is unreachable. Use the test button on the card — the dialog names the cause: HTTP 401 for a bad key, a timeout for an unreachable host.

The error says the model does not exist or is not enabled

The model is switched off in the provider editor, or the name is wrong. Each card shows enabled / total; having models configured and none enabled is a frequent cause.

Can I use a local model like Ollama?

Yes, with no key at all. Add it with the base URL http://localhost:11434/v1 and the OpenAI format. See local engines.

How do I make it prefer one model?

Star it. Under the weighted strategy a starred model is picked four times as often, which is a blunt but effective way to steer traffic.

What is the difference between a model and a virtual model?

A model is one real model at one provider. A virtual model is a named group of models plus a strategy, so asking for it asks the strategy which one to use. multillm is a virtual model that exists from the start.

Does it work with tool calling?

Yes. The tool schema passes through and the calling convention is translated per provider. A parameter a provider does not understand is dropped rather than causing an error.

Accounts and cost

How is cost calculated?

From the token counts providers report in their responses. When a provider reports nothing, the number is estimated and marked as such. Your provider's dashboard remains authoritative.

Can I set a spending limit?

Yes, as a daily budget. The usage panel warns at 80 percent. It is a warning, not a cut-off — requests keep working.

Who can see my usage?

Only your own account, and the admin's user list. In the container each user has an isolated profile, so members cannot see each other's history.

Where are my provider keys stored?

In your user profile directory, on your machine. They are compared as hashes where a lookup happens, and never leave the machine except to authenticate to the provider.

Docker and updates

Why does nothing start after a reboot?

Because restart: "no" is set deliberately. A container that starts itself and stays unreachable is worse than one you start yourself. docker compose start when you need it.

Can I reach the proxy from the internet?

Not directly — there is no TLS. Put a reverse proxy with a certificate in front, and set MULTI_LLM_COOKIE_SECURE=1. See HTTPS reverse proxy.

How do I update?

The app tells you a new version exists and stops there. Nothing is installed automatically. Download, install over the old version, restart.

Does the update check phone home?

It fetches one small file from GitHub, so your IP address is visible to them. Switch it off under Settings › App to make no outbound request at all.

I want a remote team to use this. What is the minimum?

Put it behind HTTPS, leave MULTI_LLM_ALLOW_SIGNUP unset once your accounts exist, and give each person their own key. The rest is in security.
