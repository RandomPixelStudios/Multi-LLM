Everything about Multi LLM.

Multi LLM puts every LLM provider you have keys for behind one local OpenAI-compatible endpoint. These pages cover installing it, connecting your tools, and every setting that changes how it behaves.

The short version

If you only read one thing, read this. Three values connect any OpenAI-compatible tool to Multi LLM, and nothing else is required to get a first request through.

Base URL
http://localhost:5000/v1 — the port is changeable in Settings → API.
API key
Shown in the app under API → API Keys. Copy it once and paste it into your tool.
Model
Any enabled model name, or a virtual model you created. The multillm bundle picks a model for you.
That is the whole setup

Everything else in these pages is optional. If the three values work, you can start using your tools right away and read the rest later.

Before you start

  • An OpenAI account or any provider key. Multi LLM does not include a model; it routes to providers you already pay for. Local engines such as Ollama need no key at all.
  • Network access to whichever providers you configure, or to localhost if you run a local engine.
  • One free port. The desktop app uses 5000 by default. The container always uses 5000, so the host port must be free.
  • Nothing to compile. Every platform ships a ready-made package.
Multi LLM is beta

The API shape may change between versions, and provider behaviour is outside our control. Keep a copy of your configuration before updating — see backup.
